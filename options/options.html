Files changed

Make the Files changed tab of a pull request quicker to review.

Lockfiles, snapshots, build output and other generated files start collapsed, so you see the code that matters first.

One pattern per line. A file that matches any of them counts as generated.

  • *any characters except “/”
  • **any path, across folders
  • *.min.jsno “/”: matches the file name in any folder
  • dist/**with “/”: matches that path in any folder
